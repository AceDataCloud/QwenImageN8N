# Privacy

The node sends the selected prompt, model, size, optional public reference image URLs, and API token to https://api.acedata.cloud. Task queries send only the specified task ID(s) and token to the same host. The node stores no independent telemetry and reads no local files or environment variables. n8n stores the token in its credential store. Do not include tokens in exported workflows or prompts.

See [Ace Data Cloud's privacy policy](https://platform.acedata.cloud/privacy) and [current Qwen Image pricing](https://platform.acedata.cloud/models).
