# Contributing

Use Node.js 24 and pnpm 11. Run pnpm install --frozen-lockfile --ignore-scripts, pnpm run build, pnpm run lint, and pnpm test. Tests mock the HTTP boundary and do not submit billable media. Keep the package limited to Qwen Image, avoid runtime dependencies, and include an API contract and real task evidence for new operations. Do not commit keys, private media, or raw request payloads. Submit changes through a pull request.
